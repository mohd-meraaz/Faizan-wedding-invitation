# Royal Elegance

A mobile-first, animated digital wedding invitation template.

## Quick start

Open `index.html` in a browser, or serve locally:

```bash
npx serve .
```

## Customize

Edit `js/config.js` — couple names, date, venue, events, photos, music URL, and guest wishes.

## Features

- Ornate double-door entrance with sparkle burst
- Scratch-to-reveal wedding date
- Live countdown
- Photo story carousel
- Event details, venue map, dress code
- RSVP form (demo / mock submit) with success animation
- Guest wishes wall
- Persistent mute toggle + floating RSVP shortcut
- `prefers-reduced-motion` support
